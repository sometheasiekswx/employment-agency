# Delivery plan

1. Workspace and career facts: atomic storage, provenance, confirmation/conflicts, import limits. Verify corruption and unconfirmed-fact rejection.
2. Discovery and profiles: source adapters, safe URL retrieval, hard/soft filtering, salary/eligibility uncertainty. Verify fixtures and live public endpoints separately.
3. Documents and runs: bounded resumable jobs, immutable versions, DOCX/PDF/LaTeX/EML, fact-only provider selection. Verify parsed outputs and cancellation/resume.
4. Local UI/CLI: complete onboarding, facts, search, run/review and export flows. Verify real browser desktop/mobile and hostile origin requests.
5. Privacy/recovery/release: export restore, source/history allowlist, dependency review, CI and wheel install, private pinned integration, authorized GitHub rename/publication and remote verification.

Use Python's standard library for storage, HTTP and network; three document libraries are the only runtime dependencies. No third-party application code is copied from the private pilot. Preserve private checkout and history. Publish only after blockers are resolved; disclose paid-provider and platform checks not run.
