# Use one Removed section for roles and applications

Remove moves the role and all its application versions to a single Removed section from either Opportunities or Applications. The section preserves documents, prior decisions and history, including submitted snapshots. Restore returns records to their previous lists. This supersedes [ADR 0007](0007-reversible-opportunity-removal.md), whose separate browsing and application decisions required two actions to set a role aside.

Current applications marked Rejected by an older version appear in Removed. Restoring one returns it to Draft and retains the rejection in its activity. A past rejection on an older version does not remove a newer application or a preserved submission.
