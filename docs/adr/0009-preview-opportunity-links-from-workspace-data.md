# Preview opportunity links using recorded information

On 8 November 2026 the owner chose to show a preview rendered from stored job information when someone follows a company or listing link. An explicit action opens the destination in a separate tab. Source websites can block embedding, and rendering the stored record gives the local app, hosted workspace and public showcase the same preview while keeping their existing content security policies. [Browser embedding rules](https://www.w3.org/TR/CSP3/#directive-frame-ancestors)

[ADR 0010](0010-try-live-job-listing-previews.md) supersedes this decision for job listings in private workspaces.
