# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

People preparing and reviewing their own career applications. The owner uses the app locally with a separate private career workspace. Developers need conventional, readable React/Next.js code and shared Python services.

## Product Purpose

Turn confirmed career evidence and job requirements into reviewable application documents. Success means users can inspect evidence, edit a new draft, find exact document versions, and record their own decisions without losing data.

## Operating Context

A local Python server serves a static React/Next.js interface and application API. A separate invite-only hosted pilot uses the same services with authenticated cloud storage. Career facts, job records, decisions and documents are private data, never build inputs.

## Capabilities and Constraints

Preserve all existing local and hosted workflows, including setup/folder selection, career evidence and master reconciliation, profiles, discovery/ranking, bounded preparation, editing/versioning, comments/decisions, history, export and recovery. Hosted restrictions remain explicit. No automatic sending, employer submission, paid requests, cloud upload of local workspaces or private installation upgrade.

The owner explicitly confirmed product/workflow preservation for this redesign. Python services and storage remain authoritative. Submitted snapshots and canonical document links retain their integrity rules. Empty, busy, success, error, permission and reduced-motion states must remain usable.

## Brand Commitments

Keep the Employment Agency name and truthful review-first language. The owner requested React Bits and Apple-inspired design, and confirmed a calm workspace with clearer hierarchy, compact navigation and restrained motion. The confirmed palette is Sky Blue #0593C6 and White #FCFFFF, with Hot Pink #D83995 accents and accessible text pairings. Public demonstrations use explicitly fictional experience with verified, dated real-job snapshots. No fabricated career claims, metrics, qualifications or customer evidence.

## Evidence on Hand

Existing Python, frontend and browser acceptance suites; fictional browser fixtures; documented local/hosted boundaries and systems design. Public demos use marked fictional candidate records and sourced public job metadata. Real private career data never belongs in screenshots, tests or public documentation. Live cloud acceptance is distinct from fake-provider test results.

## Product Principles

- The user controls confirmation, document versions and submission decisions.
- Personal data remains separate from reusable application software.
- Shared server rules govern both interfaces.
- Preserve drafts and make failures recoverable.
- Make the next useful action easy to find without hiding important warnings.
