# Explicit final approval for external application actions

On 31 October 2026, the owner confirmed the proposed Apply For Me feature will start locally on a Mac with a visible browser, supporting email and one job-site workflow. It prepares/fills the application, then requires a final Send/Submit confirmation for that application before performing the external action; review decisions remain distinct from submission authorization. This trades a single-click send for an inspectable final action because an external email or submission cannot be undone by restoring the local workspace; hosted execution is deferred, and the specific provider/site, registration and agent integration remain open.

This records an agreed design direction, not an implemented capability or authorization to send an application during planning. Existing manual Submitted behavior and immutable document snapshots remain unchanged.

Subsequent interview clarification: Gmail and LinkedIn are the selected channels, Codex the first local agent, and signup/sign-in/verification remain user-completed. LinkedIn's permitted integration/execution path is unresolved; choosing that channel is not a claim of approved API access or agreement to a manual-only handoff.

The owner subsequently requested proceeding past the LinkedIn integration restriction ("Bypass it"). The feature plan consequently explores experimental visible-browser Easy Apply automation, while retaining the already-confirmed user-handled verification and final submission approval. This is not evidence of provider approval, a working adapter, or authorization to perform a live application in this planning task; the implementation plan must prove feasibility and report blocked/unsupported states honestly.
