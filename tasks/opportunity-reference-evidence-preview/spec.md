# Job references, requirement evidence and listing previews

- **Job reference.** Copy the displayed title, company, full workspace job ID and original listing link when available with one action from a listing's details. Provide the same text for manual copying if the browser denies clipboard access. Agents resolve the exact ID in the selected workspace. [Glossary](../../GLOSSARY.md)
- **Requirement evidence.** **I have this skill** saves the exact requirement as a confirmed skill in Career Profile and links it to the role. A written example saves a separate confirmed fact with user-supplied provenance. A successful save shows the linked evidence and a green check. Equivalent wording on other listings reuses the same skill. Earlier job-only confirmations can be added to Career Profile from the same row. Failed example saves keep the entered text for retry. Work eligibility remains a separate decision.
- **Source preview.** A normal activation of a listing or company link in a touch-first browser opens a full-screen preview in the app. It attempts the live site after the tap. Saved details and Open in new tab stay available while it loads and if the site restricts framing. Done returns to the selected role and link. Desktop links open the original URL in a separate tab, including at narrow window sizes. [ADR 0011](../../docs/adr/0011-mobile-source-viewer-and-desktop-links.md)
- **Verification.** Exercise one-click copy and clipboard denial, durable evidence for both save paths, safe rendering and fallback for listing links, and the built UI with fictional local and hosted workspaces. The public showcase uses fictional data and read-only career evidence.
