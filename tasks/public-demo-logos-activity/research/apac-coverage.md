The Melbourne supplement is maintained separately. All 21 exact vacancy URLs returned HTTP 200 on the final check. Eighteen pages displayed apply controls and the three Tencent detail API responses returned the relevant requisition and city. A position counts after reviewing the listed location, duties, mandatory qualifications, experience and language. The same description and team under different requisitions or levels count once where the postings describe the same work. For Flexport’s duplicate Shanghai software engineering description, the Software Engineer II listing was retained. Tencent’s Chinese-language adverts retain the original posted title and actual location. They did not state a language requirement. Sponsorship and work authorization remain unknown unless established by the source.

The header PNG and the corresponding file at (www.ncs.co) have identical visible pixels and alpha at 132×30. NCS and Magnolia both confirm that the provider hosts the corporate sites.
