# Keep opportunity removal separate from application decisions

On 7 November 2026, the owner chose reversible, workspace-wide removal from Recommended, All roles and Saved, with a Removed view for restoration and optional reasons. Existing applications remain accessible in Applications and History; removal neither rejects an application nor deletes documents, and refreshing or reimporting the same listing must preserve the user's removal decision. This trades permanent deletion and per-profile hiding for fast, recoverable triage without losing application evidence or letting rediscovery undo a user's choice.
